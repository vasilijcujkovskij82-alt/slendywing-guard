# SlendyWing Guard

Discord-бот для сервера **SlendyWing**. Следит за голосовыми каналами в категории TempVoice и запрещает роли `Нарушитель` просмотр и подключение к ним.

## Что делает

- При создании нового голосового канала в категории TempVoice сразу ставит роли `Нарушитель` запрет `Просмотр канала` и `Подключиться`
- При запуске проходит по уже существующим каналам в этой категории и закрывает их
- Пишет в консоль, какие серверы видит, какая категория найдена и сколько каналов закрыто

## Настройки

Все ID зашиты в `index.js`:

| Что | Значение |
|---|---|
| Сервер | `1283395341881835581` |
| Категория TempVoice | `1435283815789760513` |
| Роль «Нарушитель» | `1563532837456584824` |

Токен берётся из переменной окружения `TOKEN` (локально — из файла `.env`).

## Запуск на компьютере

1. Двойной клик по ярлыку **SlendyWing Guard** на рабочем столе
2. При первом запуске откроется Блокнот — впиши токен после `TOKEN=`, `Ctrl+S`, закрой Блокнот
3. Окно должно оставаться открытым, пока бот работает

## Тексты и редактор

Все тексты команд лежат в `content.json` и правятся через локальный редактор — ярлык **EDITOR - SlendyWing** на рабочем столе (`http://127.0.0.1:3060`).

Сохранение в редакторе делает коммит и пуш, дальше GitHub Actions запускает деплой на Render.

Бот перечитывает `content.json` на лету, так что правки видны без перезапуска.

## Эмодзи с других серверов

В текстах можно писать коротко — `:smug:` — бот сам подставит полный вид `<:smug:1234567890>`.

Откуда берутся эмодзи:

1. эмодзи приложения (работают на любом сервере),
2. эмодзи всех серверов, где стоит бот,
3. файл `emojis.json` — ручные соответствия для эмодзи с чужих серверов.

Пример `emojis.json`:

```json
{
  "smug": "1453377377286623419",
  "necoarclumina": "a:1435270103888433316"
}
```

Префикс `a:` означает анимированный эмодзи.

В редакторе есть панель «Эмодзи»: нажми на нужный — в поле с курсором вставится `:название:`.

Чтобы эмодзи с чужих серверов отображались, у роли бота должно быть право **Использовать внешние эмодзи** (Use External Emojis). При запуске бот пишет в консоль, какие эмодзи не нашёл и есть ли у него это право.

## Требования на сервере

- Роль бота должна быть **выше** роли `Нарушитель`
- У бота должно быть право **Управлять ролями** (Manage Roles)
- Бот должен быть приглашён на сервер

## Хостинг на Render

1. Залей эти файлы в репозиторий на GitHub (публичный)
2. На [render.com](https://render.com) → `New` → `Web Service` → подключи репозиторий
3. Render сам прочитает `render.yaml`
4. В разделе `Environment` добавь переменную `TOKEN` со значением токена бота
5. `Deploy`

После деплоя бот доступен по адресу вида `https://slendywing-guard.onrender.com`.

### Про бесплатный тариф Render

Бесплатный Web Service **засыпает через 15 минут** без входящих HTTP-запросов. Пока он спит — бот офлайн.

Чтобы этого не было:

- либо раз в 10 минут дергать адрес бота бесплатным пингером (например, `cron-job.org`),
- либо взять платный тариф Render (не засыпает),
- либо оставить бота на своём компьютере.
